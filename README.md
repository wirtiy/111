# Moon Light — этап 1 (50+ функций)

## Запуск
1. Установите Python 3.10+.
2. Запустите `run.bat` или `python server.py`.
3. Сайт: http://127.0.0.1:8000
4. Админ-панель: http://127.0.0.1:8000/admin

**Демо-администратор:** `admin@moonlight.local`  
**Пароль:** `MoonLight2026!`  
После демонстрации смените пароль в исходной БД/реализуйте управление паролями перед публикацией.

SQLite автоматически создаёт `moon_light.db` при первом запуске. Не удаляйте файл БД, если хотите сохранить данные.

## API
- `GET /api/health`, `/api/rooms`, `/api/faqs`, `/api/reviews`, `/api/availability?checkin=YYYY-MM-DD&checkout=YYYY-MM-DD`
- `POST /api/register`, `/api/login`, `/api/logout`, `/api/bookings`, `/api/messages`, `/api/reviews`
- Администратор: `GET /api/stats`, `/api/bookings`, `/api/messages`, `/api/users`, `/api/reviews/all`, `/api/coupons`, `/api/tasks`, `/api/settings`, `/api/audit`
- Администратор CRUD: `POST /api/rooms`, `/api/coupons`, `/api/tasks`, `/api/faqs`; `PATCH /api/{bookings|messages|reviews|rooms|users|tasks|coupons|faqs}/ID`; `DELETE /api/{rooms|users|tasks|coupons|faqs}/ID`

## Ограничения учебной версии
Сессии хранятся в памяти сервера; пароли хешируются SHA-256 без соли (для учебного проекта, не production). Перед публикацией в интернете нужны усиленное хеширование паролей, CSRF-защита, HTTPS, безопасные cookie, rate limiting, восстановление пароля и полноценные тесты. Платёжная система и отправка email не подключены.
