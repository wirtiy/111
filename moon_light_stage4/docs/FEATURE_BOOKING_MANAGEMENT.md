# Feature: управление бронированиями

Сценарии API:
- создание бронирования;
- просмотр собственных бронирований через `GET /api/my-bookings`;
- проверка доступности номеров;
- административное изменение статуса и оплаты;
- CSV-экспорт бронирований.

Проверка: создать бронь, проверить её в личном кабинете и административном списке, затем проверить CSV.
