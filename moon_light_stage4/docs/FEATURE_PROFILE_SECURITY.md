# Feature: профиль и безопасность

Сценарии:
- `GET /api/profile`;
- `PATCH /api/profile`;
- `POST /api/change-password`;
- просмотр собственных бронирований;
- разграничение пользовательских и административных маршрутов.

Учебное приложение: перед публичным запуском добавьте HTTPS, CSRF-защиту, rate limiting, безопасное хеширование паролей и тесты.
