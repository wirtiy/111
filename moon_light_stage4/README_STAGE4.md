# Moon Light — этап 4: Git и feature-ветки

Проект продолжает Flask-версию этапа 3. Структура веток и описание отдельных feature находятся в `docs/`.

Запуск:
1. Установите Python 3.10+.
2. Запустите `run.bat` — зависимости установятся из `requirements.txt`.
3. Откройте `http://127.0.0.1:8000`; админ-панель: `/admin`.

Демо-администратор: `admin@moonlight.local` / `MoonLight2026!`.

Проверка синтаксиса: `python -m py_compile app.py server.py`.
