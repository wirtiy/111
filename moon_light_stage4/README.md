# Moon Light — этап 3 (Flask)

## Запуск на Windows
1. Установите Python 3.10 или новее.
2. Распакуйте архив.
3. Запустите `run.bat` (он установит Flask и запустит приложение).
4. Откройте `http://127.0.0.1:8000`.
5. Админ-панель: `http://127.0.0.1:8000/admin`.

Администратор: `admin@moonlight.local` / `MoonLight2026!`

## Что сделано
- Добавлена точка входа Flask (`app.py`).
- Flask обслуживает главную страницу и админ-панель.
- API-запросы проксируются к сохранённой логике этапа 2.
- Существующая SQLite-база и её миграции сохранены.
- Добавлена Flask-проверка `GET /health`.
- API-совместимость сохранена, поэтому текущий HTML и JS не требуется переписывать.

## Архитектура
Браузер → Flask (порт 8000) → внутренний API-сервер (127.0.0.1:8001) → SQLite.
Внутренний API доступен только локально; снаружи открыт Flask.

## Проверки
Python-файлы проверены компиляцией. Полноценный запуск требует установленного Flask (`pip install -r requirements.txt`). Проверьте на своём компьютере главную страницу, вход администратора, создание бронирования и `http://127.0.0.1:8000/health`.

## Важно
Это учебная архитектура переходного этапа: Flask пока выступает внешним веб-сервером и API-шлюзом, а обработчики этапа 2 сохранены для совместимости. Для следующего этапа можно перенести обработчики напрямую в Flask Blueprints и добавить тесты. Не публикуйте демо-пароль. Для реального сайта нужны безопасное хеширование паролей, HTTPS, CSRF-защита и постоянные сессии.
