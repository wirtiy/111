# Moon Light — этап 0

Учебный проект хостела: исходный HTML-интерфейс подключён к простому Python HTTP-серверу.
На этом этапе данные хранятся в словарях Python, без базы данных и сторонних библиотек.

## Запуск
1. Установите Python 3.10 или новее.
2. Откройте папку проекта.
3. Запустите `run.bat` или выполните `python server.py`.
4. Откройте http://127.0.0.1:8000

## Реализовано на этапе 0
- Раздача HTML через Python.
- API проверки состояния `/api/health`.
- Создание заявок `/api/bookings`.
- Проверка дат, количества гостей и типа номера.
- Расчёт количества ночей и стоимости.
- Хранение заявок в словаре Python.
- Создание сообщений обратной связи `/api/messages`.
- Просмотр заявок и сообщений через GET API.

## Важно
Данные хранятся только в оперативной памяти и пропадают после остановки сервера.
Это учебная локальная версия: нет настоящей оплаты, отправки email и подтверждения наличия мест.
На следующем этапе подключим SQLite и расширим функционал.
